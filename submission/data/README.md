# Data

The benchmark is in `human/`: `annotations.jsonl` contains all text and
human labels, `splits.json` fixes train/validation/test IDs, and
`statistics.json` contains counts and structural checks.

See `human/README.md` for the schema, `datasheet.md` for construction and
scope, and `annotation_guide.md` for instructions. Predictions are in
`../results/`, separate from reference labels.
