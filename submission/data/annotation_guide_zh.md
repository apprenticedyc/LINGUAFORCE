# LINGUAFORCE 人工标注说明

## 任务

请只根据对话内容判断语言是否对听者施加了负面压力。这里的压力是指：说话者试图推动听者采取某个行动，或让听者更难选择其他行动。

普通请求、建议、事实说明和基于理由的说服，不自动算作负面压力。需要结合完整对话判断。不要参考模型答案、旧标签或其他人的标注。

## 每条对话填写的内容

1. `binary`：是否存在负面压力，填 `0` 或 `1`。
2. `intensity`：总体压力强度，填 `0`--`5`。
3. `D1`--`D7`：每个维度填 `0`--`3`。
4. `A1`--`D4`：适用的策略类型填 `1`，不适用填 `0`。可以多选。
5. `notes`：只有在判断困难、存在歧义或需要说明时填写。

## 二分类和总体强度

| 值 | `binary` 含义 | `intensity` 含义 |
|---:|---|---|
| 0 | 没有负面压力 | 没有压力 |
| 1 | 存在负面压力 | 极轻微 |
| 2 |  | 较弱 |
| 3 |  | 中等 |
| 4 |  | 强 |
| 5 |  | 极强 |

`intensity` 判断整体压力，不是策略数量。对话可能只有一种策略但压力很强，也可能有多种策略但总体压力不高。

## 七个维度

所有维度均填 0--3：`0` 无，`1` 低，`2` 中，`3` 高。

| 维度 | 判断什么 |
|---|---|
| `D1` Directive force | 说话者推动听者采取目标行动的力度。 |
| `D2` Option constraint | 听者可接受的选择是否被压缩。最后通牒、二选一和威胁后果通常提高该分数。 |
| `D3` Normative pressure | 是否利用责任、道德、身份、权威、群体规范或人情债施压。 |
| `D4` Emotional pressure | 是否利用内疚、羞耻、恐惧、怜悯等情绪取得服从。 |
| `D5` Deceptiveness | 是否有对事实、记忆、共识或承诺的误导；必须有对话语境支持，不能仅因说法未经证实就判高。 |
| `D6` Toxicity | 是否有侮辱、贬低、脏话或明显敌意。 |
| `D7` Explicitness | 压力或目标行动表达得有多直接。明说“你必须留下”通常比暗示更直接。 |

维度之间可以同时较高。例如，“大家都因你失望，你必须留下”可能同时具有规范压力、情绪压力、指令性和较高直接性。`D7` 表示表达方式，不等于总体压力强度。

## 策略类型

| 类型 | 名称 | 简要判断 |
|---|---|---|
| `A1` | Request/Advice | 普通请求或建议，意图透明，通常作为低压力对照。 |
| `A2` | Directive/Order | 直接命令或要求服从。 |
| `A3` | Rational Persuasion | 主要依靠理由、证据或专业意见说服。 |
| `B1` | Promise/Inducement | 用利益、奖励或承诺换取行动。 |
| `B2` | Threat/Warning | 用损害、惩罚或不利后果推动行动。 |
| `C1` | Moral Appeal/Guilt | 用良心、道德评价或内疚感推动行动。 |
| `C2` | Obligation/Duty | 用职责、身份或角色义务推动行动。 |
| `C3` | Value Judgement/Shaming | 给听者贴自私、无情等负面标签，促使其服从。 |
| `C4` | Authority | 借助上级、专家、身份或地位要求服从。 |
| `C5` | Conformity/Social Proof | 用“大家都这样”“别人都同意”等群体规范施压。 |
| `C6` | Reciprocity/Debt | 用过去的帮助或人情债要求回报。 |
| `D1` | Emotional Manipulation | 伪装脆弱、夸大痛苦或利用情绪弱点改变决定。 |
| `D2` | Deception/Gaslighting | 歪曲事实、否认记忆或制造误导性叙述。 |
| `D3` | Logical Trap/False Dilemma | 制造虚假二选一或其他逻辑陷阱，压缩选择。 |
| `D4` | Verbal Abuse/Toxicity | 用明显辱骂、贬损或敌意推动服从。 |

策略类型可以多选。`A1`、`A3` 本身不一定是负面压力；是否为负面压力仍以 `binary` 和整体语境为准。没有任何适用策略时，所有策略列填 `0`。

## 标注流程

1. 先读完整对话，再填写 `binary` 和 `intensity`。
2. 再填写 `D1`--`D7`。
3. 最后填写策略类型。
4. 不确定时先保留判断，并在 `notes` 写明原因；不要查看旧答案。

20 个文件是对 4,066 条对话的分片，不是 20 份重复副本。要报告人工一致性，至少应从这些分片中抽取一批对话，由第二名标注者在不知道第一人答案的情况下独立重标，再对分歧进行复核。
